Icon-themes install cmds

  Install with defaults:


./install.sh
or
./install.sh standard
or
/install.sh all



Install to specific directory:


./install.sh --dest /path/to/destination



Install theme with custom name to specific directory:


./install.sh --name namehere --dest /path/to/destination



Install multiple color versions:


./install.sh color1 color2



mix and match options as needed.
