Firefox enable user.css

   * Enable userChrome.css and userContent.css in Firefox:
   * Go to about:config
   * Search for: toolkit.legacyUserProfileCustomizations.stylesheets
   * Set it to true
 * Locate your Firefox profile folder:
   * Go to about:support
   * Under “Profile Folder”, click “Open Folder”
 * Create or edit userChrome.css and userContent.css
   * Inside your profile folder, go tochrome/ (create it if it doesn't exist).
   * Create or edit userChrome.css or userContent.css
   * Paste your CSS code into relevant CSS file
 * Restart Firefox to apply changes.
