Typographic symbols in writing

  Various typographic symbols, including:
 * Comma ( , )
 * Period ( . )
 * Question Mark ( ? )
 * Exclamation Mark ( ! )
 * Quotation Marks (" ")
 * Asterisk ( * )
 * Hash/Pound Sign ( # )
 * At Sign ( @ )
 * Hyphen/Minus Sign ( - )
 * Semicolon ( ; )
 * Ellipsis ( ... )

These symbols are commonly used in writing and digital communication.
