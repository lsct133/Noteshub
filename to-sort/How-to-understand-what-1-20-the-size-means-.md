How to understand what 1/20 the size means.

  That phrase trips a lot of people up until you get used to how fractions
describe size comparisons. Let’s break it down:



--------------------------------------------------------------------------------


STEP 1: READ IT LITERALLY

 * "1/20 the size" means "one out of twenty equal parts of the size."



--------------------------------------------------------------------------------


STEP 2: THINK OF DIVIDING

 * Imagine the original object’s size = 100%.
 * If you divide that into 20 equal parts, each part is 1/20.
 * So "1/20 the size" = 1 part out of 20 = 5% of the original.



--------------------------------------------------------------------------------


STEP 3: USE A CONCRETE EXAMPLE

 * Suppose something is 200 cm long.
 * "1/20 the size" would be:120×200=10&nbsp;cm201 ×200=10&nbsp;cm
 * So the new size is much smaller (10 cm instead of 200 cm).



--------------------------------------------------------------------------------


STEP 4: COMPARE TO "TIMES BIGGER/SMALLER"

 * "1/20 the size" = "20 times smaller."
 * Conversely, "20 times the size" would mean "20 times bigger."



--------------------------------------------------------------------------------

👉 A QUICK MEMORY HACK:

 * "1/n the size" = Divide the original by n.
 * "n times the size" = Multiply the original by n.



--------------------------------------------------------------------------------


CAN THE NUMBER `20`BE BIGGER?

Yes. That denominator (the number on the bottom of the fraction) tells you how
many equal parts you’re dividing the whole into:
 * 1/2 the size → half as big (divide by 2).
 * 1/5 the size → one-fifth as big (divide by 5).
 * 1/20 the size → one-twentieth as big (divide by 20).
 * 1/100 the size → one-hundredth as big (divide by 100).
 * 1/1,000 the size → one-thousandth as big (divide by 1,000).

So the larger the denominator, the smaller the fraction becomes.

👉 EXAMPLE: IF SOMETHING IS 200 CM LONG:

 * 1/2 the size = 100 cm
 * 1/20 the size = 10 cm
 * 1/100 the size = 2 cm
 * 1/1000 the size = 0.2 cm

🔑 KEY IDEA

The denominator (the number on the bottom, like 2, 5, 20, 100…) tells you how
many slices you cut the whole into.
 * The more slices, the smaller each slice will be.



--------------------------------------------------------------------------------




🍕 PIZZA ANALOGY



Imagine a pizza:


 * Cut into 2 slices → each slice = 1/2 (pretty big).
 * Cut into 5 slices → each slice = 1/5 (smaller).
 * Cut into 20 slices → each slice = 1/20 (tiny sliver).
 * Cut into 100 slices → each slice = 1/100 (paper thin).



So when you say “1/20 the size”, you’re choosing one slice out of 20 — much
smaller than 1/2 or 1/5.



--------------------------------------------------------------------------------




⚡ QUICK INTUITION TRICK



Think of the denominator as “divide by that number”:


 * 1/2 size = divide by 2
 * 1/10 size = divide by 10
 * 1/20 size = divide by 20



👉 The bigger the denominator, the smaller the result.



--------------------------------------------------------------------------------




🧠 MENTAL IMAGE



If the whole = 100%:


 * 1/2 = 50%
 * 1/5 = 20%
 * 1/20 = 5%
 * 1/100 = 1%



You can see the percentage shrinking as the denominator grows.
